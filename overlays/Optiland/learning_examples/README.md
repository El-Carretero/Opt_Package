# 첫 Optiland 예제: 유리 렌즈 하나로 평행광 모으기

이 예제에서는 **평행한 빛이 양볼록 렌즈의 두 면에서 굴절하여 모이는 과정**을 살펴봅니다. 이어서 렌즈 중심 가까이를 지나는 광선과 가장자리를 지나는 광선이 정확히 같은 위치에 모이지 않는다는 점을 확인합니다. 처음에는 그림의 위쪽 광선 경로만 보고, 다음에 아래쪽 초점 확대 그림과 거리 설명을 읽으면 됩니다.

## 실행

1. 이 폴더의 **`RUN.bat`를 더블클릭**합니다. 이미 설치된 상위 Optiland 폴더의 `.venv`를 사용합니다.
2. 콘솔에 `PASS`가 나오면 [결과 그림](output/single_lens_rays.png)을 엽니다.
3. 입력값을 바꾸려면 [single_lens.py](single_lens.py) 맨 위의 상수만 수정하고 다시 실행합니다. 같은 이름의 결과 파일은 새 결과로 덮어씁니다.

다른 컴퓨터로 복사했다면 상위 폴더의 `install\install.bat`로 환경을 먼저 다시 만드세요. `.venv` 자체를 다른 컴퓨터에서 그대로 사용하는 것은 권장하지 않습니다. 예제는 자신의 위치를 기준으로 파일을 읽고 쓰므로 특정 사용자 이름이나 드라이브 경로에 의존하지 않습니다.

## 입력과 단위

빛은 왼쪽에서 오른쪽, 즉 `+z` 방향으로 진행합니다. 앞면 꼭짓점이 `z=0 mm`, 뒷면 꼭짓점이 `z=5 mm`입니다. `y`는 광축으로부터의 높이입니다.

| 코드의 값 | 기본값 | 의미 |
|---|---:|---|
| `N_GLASS` | 1.5 | 유리 굴절률. 앞뒤 공간의 굴절률은 1.0입니다. |
| `R_FRONT_MM` | +50 mm | 앞면 곡률 반지름. 곡률 중심이 면의 오른쪽에 있으면 양수입니다. |
| `R_BACK_MM` | −50 mm | 뒷면 곡률 반지름. 이 부호 조합이 양볼록 렌즈를 만듭니다. |
| `THICKNESS_MM` | 5 mm | 광축 위에서 측정한 렌즈 중심 두께입니다. |
| `BEAM_DIAMETER_MM` | 16 mm | 입사 평행광의 지름입니다. 광선의 입사 높이는 −8…+8 mm입니다. |
| `WAVELENGTH_UM` | 0.55 µm | 550 nm. Optiland에 넘기는 파장의 단위는 µm입니다. |
| `SCREEN_AFTER_REAR_MM` | 60 mm | 뒷면 꼭짓점부터 기록용 관측면까지의 거리입니다. 렌즈의 초점거리를 설정하는 값이 아닙니다. |
| `N_RAYS` | 9 | 그림에 표시할 광선 수입니다. |

`IdealMaterial(1.5)`를 사용하므로 파장에 관계없이 굴절률이 일정한 이상적인 유리입니다. 실제 유리 제품을 지정한 예제는 아닙니다.

## 그림에서 읽을 것

위쪽 그림은 Optiland가 계산한 각 면의 교점을 직선으로 연결한 실제 광선 경로입니다. 렌즈 모양 역시 Optiland의 구면 형상에서 얻었습니다. 그림은 가독성을 위해 가로와 세로 축척이 다르므로, 화면에서 보이는 각도를 각도기로 측정하면 안 됩니다.

아래 왼쪽은 초점 부근 확대 그림입니다. 가장자리 광선이 광축을 만나는 위치가 중심에 가까운 광선의 위치보다 렌즈 쪽에 있습니다. 구면 렌즈가 만드는 **구면수차**의 가장 기본적인 모습입니다. 중앙 광선은 광축 위로 그대로 진행하므로 이 광선 하나만으로 초점 위치를 정할 수 없습니다.

아래 오른쪽의 두 거리는 출발점이 다릅니다.

- **EFL(유효초점거리)**: 뒤쪽 주평면 H2부터 근축 초점까지의 거리입니다. 주평면은 두께가 있는 렌즈의 1차 광학 작용을 표현할 때 사용하는 기준면이며, 유리 표면 자체와 같지 않습니다.
- **BFL(후초점거리)**: 렌즈 뒷면 꼭짓점부터 근축 초점까지의 거리입니다. 렌즈 뒤에 검출기 등을 배치할 때 기준으로 삼기 쉽습니다.

여기서 **근축**은 광축 가까이에서 각도가 작은 광선을 다루는 근사입니다. EFL과 BFL의 계산에는 근축 모델을 사용하고, 색깔 있는 경로에는 실제 구면 굴절을 사용합니다.

## 기본값의 예상 결과

| 양 | 값 |
|---|---:|
| EFL | 50.8474576 mm |
| BFL | 49.1525424 mm |
| 근축 초점의 좌표 `z` | 54.1525424 mm |
| 뒤쪽 주평면 H2의 좌표 `z` | 3.3050847 mm |
| 가장자리 광선(입사 높이 ±8 mm)이 광축을 만나는 `z` | 52.0810892 mm |
| 가장자리 광선이 근축 초점보다 먼저 모이는 거리 | 약 2.07145 mm |
| 두께를 무시한 얇은 렌즈 근사 EFL | 50.0000000 mm |

예를 들어 `54.1525424 − 5 = 49.1525424 mm`가 BFL입니다. `54.1525424 − 3.3050847 = 50.8474577 mm`는 반올림 오차 범위에서 EFL입니다. 얇은 렌즈 근사값 50 mm와 정확히 같아야 한다고 판단하면 안 됩니다.

## 무엇을 검산했나

주된 계산은 Optiland가 수행합니다. `trace_generic()`가 굴절과 교점을 계산하고, 각 면의 `x, y, z, L, M, N` 기록으로 그림과 CSV를 만듭니다. `L, M, N`은 각각 x, y, z 방향 코사인입니다. 마지막 면을 지난 뒤에는 공기 중에서 직선으로 진행하므로 기록된 방향으로 광축 교점 `z − y·N/M`을 구합니다.

독립적인 검산에는 공기 속 두꺼운 구면 렌즈의 근축 식을 사용합니다. 굴절률 `n`, 중심 두께 `t`, 부호가 있는 곡률 반지름 `R1, R2`에 대해:

```text
굴절력 Φ = (n − 1) × [1/R1 − 1/R2 + (n − 1)t/(n R1 R2)]
EFL = 1/Φ
BFL = [1 − t(n − 1)/(n R1)]/Φ
```

Optiland의 EFL/BFL이 이 식과 일치하는지 자동으로 확인합니다. 또한 모든 광선 기록이 유한한 값인지, 방향 벡터 길이가 1인지 검사합니다. 입사 높이 0.001 mm인 실광선의 초점이 근축 초점과 가까운지도 확인하며 기본값에서 차이는 약 `3.12 × 10⁻⁸ mm`입니다. 이 작은 수치는 이 예제의 계산 일치도이며, 실제 렌즈의 제조 정확도를 뜻하지 않습니다.

## 값을 바꿔 보는 순서

한 연습을 마치면 기본값으로 되돌린 후 다음 연습을 하세요. 아래 범위는 기본 관측면 위치에서도 결과를 보기 좋게 유지합니다.

1. **입사광을 좁히기:** `BEAM_DIAMETER_MM = 8.0`으로 바꿉니다. 렌즈 자체의 EFL/BFL은 그대로이고, 가장자리 광선의 초점이 근축 초점에 가까워집니다. 작은 구경이 구면수차를 줄이는 이유를 봅니다.
2. **면을 더 굽히기:** `R_FRONT_MM = 40.0`, `R_BACK_MM = -40.0`으로 두 값을 함께 바꿉니다. 초점이 렌즈 쪽으로 가까워지는지 확인합니다. 반지름의 절댓값이 작을수록 더 강하게 굽은 면입니다.
3. **굴절률 높이기:** `N_GLASS = 1.6`으로 바꿉니다. 같은 형상에서 광선이 더 강하게 굴절하고 초점거리가 짧아지는지 확인합니다.
4. **중심 두께 줄이기:** `THICKNESS_MM = 2.0`으로 바꿉니다. EFL과 BFL의 차이가 어떻게 달라지는지 비교합니다. 두꺼운 렌즈와 얇은 렌즈 근사의 관계를 봅니다.

임의로 매우 큰 구경이나 매우 작은 곡률 반지름을 넣으면 두 렌즈 면이 겹치거나 광선이 정상적으로 전달되지 않을 수 있습니다. 초점거리를 크게 늘리는 실험에서는 `SCREEN_AFTER_REAR_MM`도 충분히 늘려야 초점 이후까지 광선이 그림에 나타납니다.

## 만들어지는 파일

| 파일 | 내용 |
|---|---|
| [output/single_lens_rays.png](output/single_lens_rays.png) | 전체 광선 경로, 초점 확대, EFL/BFL 설명 |
| `output/ray_paths.csv` — 실행 후 생성 | 9개 광선 × 4개 기록면의 교점과 방향 코사인 |
| `output/focus_positions.csv` — 실행 후 생성 | 중앙 광선을 제외한 8개 광선의 광축 교점 |
| `output/summary.json` — 실행 후 생성 | 입력값, 라이브러리 버전, 주요 수치, 자동 검산 결과 |

CSV는 UTF-8 BOM을 포함하여 저장하므로 Windows Excel에서도 열기 쉽습니다. `.mplconfig`는 그림을 만들 때 생기는 로컬 글꼴 캐시입니다.

## 범위와 실행 버전

이 예제는 기하광학의 축상 평행광과 하나의 구면 렌즈만 다룹니다. 회절, 간섭, Airy 무늬, 편광, 실제 유리의 분산, 코팅 반사, 열렌즈, 이득, 레이저 펄스 에너지를 계산하는 예제가 아닙니다. 2차원 단면에 그린 9개 광선만으로 전체 빔의 세기 분포나 최종 집속 크기를 판단할 수 없습니다.

기본값 실행 확인: **Optiland 0.6.3+local / Python 3.12.12**, 자동 검산 `PASS`. 실행할 때 실제 버전이 `summary.json`에 다시 기록됩니다. Optiland 소스와 환경의 자세한 설치 정보는 상위 폴더의 `Readme.md` 및 `install` 폴더를 참고하세요.
